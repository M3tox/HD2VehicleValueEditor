# For general users
Hit "File" and open the .tbl files you want to change its values. It should open up a large list. Note that a lot of values have not been detected yet, those are labeled as "unknown". If you figure some of these out you can use the Issues tab and report them. When doing so always mention the ID (number on the left) and the category.

Don't forget to save your changes!

This code is from 2022. I have not looked at it since then and it probably has a few bugs, but I hope it works good enough for your projects. Happy modding!

# For developers
If you want to compile it you must link it with wxWidgets! This is the only additional library that you need to compile this code.
